# etsy-beekindbeeyourself-github-policy

Retired. This repository previously served the privacy policy for **BeeKindBeeYourself Shop
Analytics** (the shop's private Pinterest API tool) at
`https://saccoccio-prints.github.io/etsy-beekindbeeyourself-github-policy/`.

The policy now lives at one address only:

**https://beekindbeeyourself.github.io/privacy-policy/**

That is the current policy in force, the one built for the Pinterest API re-application, and the
Privacy Policy URL registered for it. It sits on the same host as the application's Main URL, which
is the pairing Pinterest's reviewer asked for. Its source is
`beekindbeeyourself/beekindbeeyourself.github.io`.

`index.html` here redirects there and carries no policy text of its own. Two published policies that
disagree is the condition this repository exists to avoid.

## Why this repository is kept rather than deleted

Deleting it would make the old address return 404. Anyone still holding that link — Pinterest,
from the denied application `1608669`, most of all — would reach a dead end instead of the current
policy. A redirect costs nothing and fails safe; a deletion does not. Retire the address, keep the
signpost.
