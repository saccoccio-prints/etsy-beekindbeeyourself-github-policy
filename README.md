# etsy-beekindbeeyourself-github-policy

Superseded. This repository previously served the privacy policy for **BeeKindBeeYourself Shop
Analytics** (the shop's private Pinterest API tool) at
`https://saccoccio-prints.github.io/etsy-beekindbeeyourself-github-policy/`.

The policy now lives at one address only:

**https://beekindbeeyourself.github.io/privacy-policy/**

That address is the Privacy Policy URL registered for the tool's Pinterest API application, and it
sits on the same host as the application's Main URL — which is the pairing Pinterest's reviewer
asked for. Its source is `beekindbeeyourself/beekindbeeyourself.github.io`.

`index.html` here is now a supersession notice pointing at that address. It deliberately carries no
policy text: two published policies that disagree is the condition this repository exists to avoid.
